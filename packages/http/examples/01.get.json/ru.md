# Получить список пользователей

[English version](en.md)

Сервер уроков отвечает на `GET /users` JSON-массивом из четырёх пользователей. Каждая вкладка запрашивает этот
список и возвращает его как есть; feature-тест проверяет, что все шесть вернули один и тот же массив.

<!-- @variants -->

## В чём разница

- **jext** разбирает тело по `Content-Type`, поэтому `data` уже массив. Неудачный запрос не бросает исключение: он
  приходит в `error`, и вкладка его бросает, как каждая вкладка превращает сбой в ошибку.
- **fetch** выполняется успешно даже для 404 и 500, поэтому `response.ok` проверяешь сам, потом вызываешь
  `.json()`, у которого тип `any`.
- **XMLHttpRequest** работает на колбэках: урок оборачивает его в `Promise`, просит `responseType = 'json'`,
  проверяет статус в `onload` и обрабатывает обрыв соединения в `onerror`.
- **axios** разбирает JSON сам и бросает исключение для любого статуса вне 2xx; тело лежит в `data`.
- **ky** бросает `HTTPError` для статуса вне 2xx; `.json<T>()` читает тело и задаёт ему тип.
- **ofetch** бросает `FetchError` для статуса вне 2xx и сразу возвращает разобранное тело.
- **axios**, **ky** и **ofetch** бросают сами, поэтому их вкладки ловят ошибку и превращают её в ту же строку
  статуса, что у остальных; без `try` код лишь выглядел бы короче.
