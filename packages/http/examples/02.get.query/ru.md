# Отфильтровать параметрами запроса

[English version](en.md)

`GET /users?role=admin&limit=10` возвращает только администраторов. Каждая вкладка отправляет одни и те же два
параметра, один из них число.

<!-- @variants -->

## В чём разница

- **jext** принимает объект в `.query()`: можно числа, булевы значения и массивы, кодирование сделано за тебя. Тот
  же объект можно передать в опциях: `http.get(url, { query })`.
- У **fetch** и **XMLHttpRequest** такой опции нет: строку собираешь через `URLSearchParams`, который принимает
  только строки, поэтому число проходит через `String()`.
- У **axios** опция называется `params`, у **ky** `searchParams`, у **ofetch** `query`. Все три принимают числа.
