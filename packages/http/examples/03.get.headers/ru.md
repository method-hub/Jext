# Отправить заголовок

[English version](en.md)

`GET /me` отвечает вошедшим пользователем, только если в запросе есть `Authorization: Bearer secret-token`; без него
сервер отвечает 401. Каждая вкладка добавляет заголовок к этому одному запросу.

<!-- @variants -->

## В чём разница

- **jext** добавляет заголовки через `.headers()`, и каждый вызов возвращает новый запрос, так что подготовленный
  запрос можно переиспользовать с другими заголовками. Для заголовка на каждом запросе к API лучше подходит клиент
  из `http.extend({ headers })`.
- **fetch**, **axios**, **ky** и **ofetch** принимают объект `headers` в опциях.
- **XMLHttpRequest** требует `setRequestHeader()` на каждый заголовок, после `open()` и до `send()`.
- Свой заголовок заставляет браузер сначала отправить CORS-preflight (`OPTIONS`); сервер уроков на него отвечает.
