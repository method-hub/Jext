# Проверить, что ресурс существует

[English version](en.md)

`HEAD` запрашивает заголовки ресурса без тела. Урок проверяет двух пользователей: `/users/1` существует, `/users/99`
отвечает 404. Каждая вкладка возвращает `[true, false]`; любую другую ошибку пробрасывает дальше.

<!-- @variants -->

## В чём разница

- **jext** не бросает исключение на 404: статус лежит в `error.status`, проверка занимает один `if`.
- **fetch** и **XMLHttpRequest** тоже никогда не бросают из-за статуса: читаешь `response.ok` или `xhr.status`.
- **axios** бросает исключение на 404, так что ответ «не существует» приходит исключением, которое надо поймать и
  разобрать.
- **ky** тоже бросает, если не задать `throwHttpErrors: false`; тогда он возвращает `Response`.
- **ofetch** по умолчанию возвращает только тело; `ofetch.raw()` с `ignoreResponseError: true` даёт ответ и его
  статус.
