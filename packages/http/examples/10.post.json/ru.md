# Создать пользователя через JSON

[English version](en.md)

`POST /users` принимает JSON-тело и отвечает 201 с созданным пользователем, который получает id 5. Каждая вкладка
отправляет один и тот же объект.

<!-- @variants -->

## В чём разница

- **jext** сериализует обычный объект в `.body()` и сам ставит `Content-Type: application/json`.
- **fetch** и **XMLHttpRequest** отправляют строки: `JSON.stringify()` и заголовок `Content-Type` на тебе. Без
  заголовка сервер получит `text/plain`.
- **axios** сериализует объекты по умолчанию; тело это второй аргумент `axios.post()`.
- У **ky** для этого есть отдельная опция `json`.
- **ofetch** сериализует обычный объект в `body` и ставит заголовок.
