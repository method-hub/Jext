# Загрузить файл

[English version](en.md)

`POST /files` принимает файл в multipart-форме и отвечает его именем, размером и типом. Каждая вкладка собирает один
и тот же `FormData` с текстовым файлом `hello.txt` на 12 байт.

<!-- @variants -->

## В чём разница

- Файл это `Blob` (или `File` из `<input type="file">`), добавленный в `FormData` с именем; третий аргумент
  `append()` становится именем, которое видит сервер.
- Отправка во всех инструментах одинаковая, как в уроке про форму: браузер сам ставит заголовок multipart.
- Разница дальше: прогресс большой загрузки. **XMLHttpRequest**, **axios** (в браузере он работает через
  XMLHttpRequest) и **jext** (`.onUploadProgress()` переключает запрос на XMLHttpRequest) сообщают его в любом браузере.
  У **ky** тоже есть `onUploadProgress`, но ему нужны потоковые тела запросов, которые есть не во всех браузерах, а без
  них он молча ничего не делает. **fetch** и **ofetch** его не сообщают.
