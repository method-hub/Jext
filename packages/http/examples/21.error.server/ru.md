# Обработать ошибку сервера

[English version](en.md)

`GET /reports/daily` отвечает 500 с телом простым текстом. Каждая вкладка возвращает статус и текст.

<!-- @variants -->

## В чём разница

- **jext** разбирает тело ошибки по `Content-Type`, так что `error.data` это текст. Он не повторяет запрос, пока не
  попросишь через `.retry()`.
- **fetch** и **XMLHttpRequest** читают текст через `.text()` и `responseText`.
- **axios** нужен `responseType: 'text'`, чтобы тело осталось строкой.
- **ky** и **ofetch** по умолчанию повторяют неудачный `GET` на 500: ky ещё до 2 раз с растущей паузой, ofetch один
  раз. Урок ставит `retry: 0`, чтобы увидеть первый ответ; без этого пользователь ждёт все попытки.
