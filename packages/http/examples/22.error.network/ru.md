# Заметить обрыв соединения

[English version](en.md)

`GET /drop` закрывает соединение, ничего не ответив, как упавший сервер или пропавшая сеть. Статуса нет, поэтому
каждая вкладка возвращает `0`.

<!-- @variants -->

## В чём разница

- **jext** возвращает `HttpError` со `status` `0`; в `error.cause` лежит отказ `fetch`.
- **fetch** отклоняет промис только в этом случае (и при отмене): любой ответ, даже 500, выполняется успешно.
- **XMLHttpRequest** вызывает `onerror`, а `xhr.status` равен `0`.
- **axios** бросает `AxiosError` без `response` (`code` равен `ERR_NETWORK`).
- **ky** бросает `NetworkError`, **ofetch** бросает `FetchError` без `response`. Оба сначала повторили бы запрос,
  поэтому урок ставит `retry: 0`.
