# Прочитать XML

[English version](en.md)

`GET /books.xml` присылает каталог из двух книг как `application/xml`. Каждая вкладка возвращает названия.

<!-- @variants -->

## В чём разница

- **jext** превращает XML в обычный объект через fast-xml-parser: `data.catalog.book` это массив `{ title, year }`,
  числа остаются числами. Тег, который встречается один раз, будет объектом, а не массивом из одного элемента, атрибуты
  не попадают в результат.
- **fetch**, **axios**, **ky** и **ofetch** читают тело как текст и передают его в `DOMParser`, а потом ищут в документе
  CSS-селекторами.
- **XMLHttpRequest** сам строит документ при `responseType = 'document'`.
