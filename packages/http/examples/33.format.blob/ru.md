# Скачать картинку как Blob

[English version](en.md)

`GET /logo.png` присылает PNG на 70 байт. Каждая вкладка возвращает тип и размер полученного файла.

<!-- @variants -->

## В чём разница

- **jext** сам возвращает `Blob` для картинок, аудио, видео и других двоичных типов.
- **fetch** и **ky** вызывают `.blob()`.
- **XMLHttpRequest** и **axios** ставят `responseType: 'blob'`; без него XMLHttpRequest вернёт строку, а axios попробует
  прочитать байты как текст.
- **ofetch** для картинки тоже возвращает `Blob`; урок передаёт `responseType: 'blob'`, чтобы тип был точным.
