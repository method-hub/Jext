# Скачать файл-вложение

[English version](en.md)

`GET /export` присылает CSV-отчёт с `Content-Disposition: attachment`: это файл для сохранения, а не таблица для показа.
Каждая вкладка возвращает тип и размер файла.

<!-- @variants -->

## В чём разница

- **jext** читает `Content-Disposition`: вложение остаётся `Blob`, даже если его тип CSV или текст, и файл можно
  сохранить как есть. JSON по-прежнему разбирается.
- **fetch**, **XMLHttpRequest**, **axios** и **ky** не смотрят на этот заголовок; урок просит у каждого `Blob`.
- **ofetch** прочитал бы `text/csv` как строку, поэтому ему нужен `responseType: 'blob'`.
