# Узнать, что не совпало со схемой

[English version](en.md)

Схема ждёт поле `age`, которого сервер не присылает. Каждая вкладка возвращает сообщения о несовпадениях.

<!-- @variants -->

## В чём разница

- **jext** возвращает `ValidationError` в `error`: `issues` перечисляет каждую проблему с путём, `value` хранит данные,
  которые не прошли. Сам запрос удался, поэтому `data` равно `null`.
- **ky** бросает `SchemaValidationError` с теми же `issues`.
- **fetch**, **XMLHttpRequest**, **axios** и **ofetch** вызывают `User.safeParse()`, который возвращает несовпадения, а
  не бросает их.
