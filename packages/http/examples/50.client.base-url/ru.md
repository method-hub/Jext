# Задать базовый адрес один раз

[English version](en.md)

Клиент создаётся один раз с адресом API, а запросы дальше идут по коротким путям. Каждая вкладка возвращает имена
пользователей 1 и 2.

<!-- @variants -->

## В чём разница

- **jext** создаёт клиент через `http.extend({ baseUrl })`; у клиента есть все методы `http`.
- У **axios** есть `axios.create({ baseURL })`, у **ky** `ky.create({ baseUrl })`, у **ofetch** `ofetch.create({ baseURL
  })`.
- У **fetch** и **XMLHttpRequest** нет клиентов: небольшая функция `api()` добавляет адрес и проверяет статус.
