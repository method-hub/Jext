# Отправлять токен с каждым запросом

[English version](en.md)

`GET /me` отвечает только с верным заголовком `Authorization`, `GET /echo/headers` показывает, что пришло. Каждая
вкладка возвращает имя пользователя и заголовок, который увидел сервер.

<!-- @variants -->

## В чём разница

- **jext**, **axios**, **ky** и **ofetch** принимают `headers` при создании клиента; запрос может добавить или заменить
  заголовки поверх них.
- **fetch** и **XMLHttpRequest** ставят заголовок в функции `api()` для каждого запроса.
