# Собрать клиент поверх другого

[English version](en.md)

Клиент приложения отправляет `X-App`; клиент администратора, сделанный из него, добавляет `Authorization`. Каждая
вкладка возвращает оба заголовка так, как их увидел `GET /echo/headers`.

<!-- @variants -->

## В чём разница

- **jext** и **ky** вызывают `extend()` у первого клиента: заголовки сливаются, а хуки добавляются после хуков первого
  клиента.
- У экземпляра **axios** тоже есть `create()`: он сливает новые настройки с настройками этого экземпляра. Перехватчики
  не копируются.
- У **ofetch** есть `create()` у клиента, но он заменяет объект `headers`, а не сливает его, поэтому урок разворачивает
  первые заголовки вручную.
- У **fetch** и **XMLHttpRequest** нет клиентов, расширять нечего: функция собирает заголовки обоих уровней.
