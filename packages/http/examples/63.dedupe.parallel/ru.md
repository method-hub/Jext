# Один запрос вместо одинаковых

[English version](en.md)

Три части страницы одновременно просят `GET /counter`. Сервер считает полученные запросы, поэтому каждая вкладка
возвращает `[1, 1, 1]`: один запрос, три ответа. Без объединения было бы 1, 2 и 3.

<!-- @variants -->

## В чём разница

- **jext** объединяет одинаковые GET и HEAD, пока первый ещё в пути, через `.dedupe()` или `http.extend({ dedupe: true
  })`. Каждый получает свою копию ответа; это не кэш, следующий запрос снова идёт в сеть. Отмена у одного вызывающего
  останавливает только его ожидание.
- У **fetch**, **XMLHttpRequest**, **axios**, **ky** и **ofetch** такого нет: `Map` промисов по URL делает это вручную.
