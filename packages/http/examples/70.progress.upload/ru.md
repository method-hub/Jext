# Показать прогресс загрузки на сервер

[English version](en.md)

`POST /upload` получает 64 КиБ и отвечает числом байтов. Вкладка возвращает ответ и то, вызывался ли её обработчик
прогресса; инструмент, который не умеет сообщать о загрузке, возвращает `null`, а его вкладка говорит, чем
воспользоваться.

<!-- @variants -->

## В чём разница

- **jext** отправляет запрос через `XMLHttpRequest`, когда задан `.onUploadProgress()`: это единственный API браузера,
  сообщающий о загрузке. Обработчик получает `{ loaded, total, percent }`, а когда приходит ответ, jext сообщает 100%,
  если браузер этого не сделал.
- **XMLHttpRequest** сообщает через `xhr.upload.onprogress`; **axios** в браузере использует его для своего
  `onUploadProgress`.
- **fetch** не сообщает о загрузке: тело запроса можно отправлять потоком только в Chromium и только по HTTP/2.
- У **ky** есть `onUploadProgress` на таком потоке: по HTTP/1.1 в Chromium загрузка падает, в остальных браузерах
  обработчик молча не вызывается.
- У **ofetch** нет опции прогресса.
