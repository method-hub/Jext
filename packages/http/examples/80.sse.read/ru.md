# Прочитать Server-Sent Events

[English version](en.md)

`GET /events` присылает три события как `text/event-stream` и завершается. Каждая вкладка возвращает данные каждого
события.

<!-- @variants -->

## В чём разница

- **jext** читает поток через `for await` по `http.sse(url)`; каждое событие это `{ event, data, id, retry }`, а разбор
  следует спецификации: комментарии, `retry:`, CRLF и данные из нескольких строк.
- **fetch**, **ky** и **ofetch** дают тело как поток; урок читает его самописным разбором, который знает только `id:` и
  `data:`.
- **axios** в браузере даёт поток только через fetch-адаптер (`adapter: 'fetch'`, `responseType: 'stream'`).
- У **XMLHttpRequest** нет потока: `responseText` растёт по мере прихода ответа, и каждый `onprogress` разбирает новое.
  В браузере для этого есть ещё `EventSource`, но только для GET без своих заголовков.
