# Получить ответ на POST потоком

[English version](en.md)

`POST /chat` принимает `{ prompt }` и присылает ответ по частям в JSON, как это делают API чатов. Каждая вкладка
возвращает ответ целиком.

<!-- @variants -->

## В чём разница

- **jext**: `.body()` делает поток POST-запросом, `.headers()` может добавить токен, `.json<T>()` разбирает `data`
  каждого события.
- **fetch**, **XMLHttpRequest**, **axios**, **ky** и **ofetch** отправляют POST как обычно и читают поток так же, как в
  уроке про чтение событий, с `JSON.parse` для каждого события.
- `EventSource` так не умеет совсем: он не отправляет ни тело, ни заголовки.
